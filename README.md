# JasperPC Website – Updated Service Photos

Vercel-ready static website for JasperPC.

## Included updates
- Uses the customer's supplied service photos for Computer Repair, Computer Maintenance, Networking, Computer Upgrades, Laptop RAM Upgrade & Maintenance and Custom PC Building.
- Retains the existing Software Installation image.
- Adds Remote Technical Support with a realistic home-working image.
- Removes the old “JASPERPC HOME SERVICE PHOTO” cover panel.
- All service cards are clickable and automatically select the service in the Job Order Request form.
- Adds Remote Technical Support to the booking form.
- Updates the Facebook button to the new JasperPC Facebook profile.
- Keeps the working Google Apps Script booking endpoint unchanged.
- No Google Calendar invitation or Google Meet is created by this website.

## Vercel
Upload the contents of this folder as a Vercel project. `index.html` must be at the project root.
